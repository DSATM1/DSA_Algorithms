Meet the stack.

A stack is a simple structure with one important rule: the last item you put in is the first one you take out. Try it below, then see how the same idea looks in Java.

Try this sequence

Start with 10, 20, 30 (30 is on top). Press Push to add 40, then Pop. The 40 you just added comes right back off.

10 → 20 → 30 → 40

Each value is available only from the top. That makes a stack feel like a pile of plates: you add and remove plates at the top.

O(1)push / pop / peek
O(n)search (typically)

The same stack in Java

For everyday Java code, prefer ArrayDeque as a stack.

java.util 
import java.util.ArrayDeque;
import java.util.Deque;

Deque<Integer> stack = new ArrayDeque<>();

stack.push(10);                 // add to the top: [10]
stack.push(20);                 // add to the top: [10, 20]
int top = stack.peek();        // read top (20), keep it there
int removed = stack.pop();     // remove and return 20
boolean empty = stack.isEmpty(); // check before popping
